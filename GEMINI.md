gemini# Find My iPhone Automate

A Python script to automatically ping you whenever one of your iCloud devices is online or its position is updated in "Find My".

## Project Overview

This project uses the `pyicloud` library to poll Apple's "Find My" service. When a target device's location is updated or it comes online, the script triggers alerts via Discord Webhooks or WhatsApp.

### Key Technologies
- **Python 3.x**
- **pyicloud**: Interface for iCloud services.
- **neonize**: WhatsApp gateway for Python (requires scanning a QR code for session initialization).
- **redu-logger, redu-config-manager, redu-build-manager**: Custom utility libraries for logging, configuration, and build tracking.
- **requests**: Used for sending Discord webhook notifications.

### Project Structure
- `main.py`: The primary entry point containing initialization, polling logic, and alert triggers.
- `requirements.txt`: Project dependencies, including links to private repositories for `redu` libraries.
- `data/`: (Generated at runtime) Stores configuration (`config.yaml`) and session data.
- `logs/`: Directory for log files generated by `redu-logger`.
- `test.py`: A simple script to test `redu-logger` connectivity.

## Building and Running

### Prerequisites
- Python 3.x installed.
- Valid iCloud credentials (Note: Find My bypasses 2FA for location data).

### Installation
Install the required dependencies using `pip`. Note that some libraries are hosted on a private repository:

```bash
pip install -r requirements.txt
```

### Running the Script
Execute the main script:

```bash
python main.py
```

On the first run, the script will prompt for:
1. Apple ID and Password.
2. Target Device Model (e.g., "iPhone 6s").
3. Preferred Alert Method (Discord Webhook, WhatsApp, or both).

## Development Conventions

### Configuration
Configuration is managed via `redu-config-manager` and stored in `data/config.yaml`. The script automatically handles first-time setup if this file is missing or empty.

### Logging
Logging is handled by `redu-logger`, which supports both local file logging and potentially remote logging. Logs are stored in the `logs/` directory.

### Alerting
- **Discord**: Requires a Webhook URL.
- **WhatsApp**: Uses `neonize`. On first use, it will prompt you to scan a QR code to establish a session, which is saved in `data/session.db`.

### Polling Interval
The default polling interval is 180 seconds (3 minutes) to avoid being rate-limited by Apple's servers. This can be adjusted in the `config.yaml` after the initial setup.
